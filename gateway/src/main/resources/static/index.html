微服务机制

门

统一入口

网关是唯一对外入口。只读接口公开，写操作要 JWT；每个 IP 限流，登录另外限次数。

册

注册与配置

服务注册到 Nacos，网关按服务名找实例；连接地址、订阅目标等配置放 Nacos，不用重启。

调

服务间调用

重放历史事件时，投递服务用 OpenFeign 调归档服务的内部接口，带内部令牌，超时和熔断都有默认值。

断

熔断与降级

网关每条路由一个熔断器。下游超时或熔断打开时返回 503 和原因，不返回假数据。

链

链路追踪

网关生成 traceId，传给下游，响应头 X-Trace-Id 带回；拿着它能在各服务日志里查同一次请求。

隔

故障隔离

三个消费组各管各的；处理不了的事件记下后跳过，一个慢接收端也拖不住其他投递。
